# Agent guide

This is a sanitized public showcase. Read this file and `README.md` before changing code.

- Keep all content fictional and generic. Never import personal media, private datasets, puzzle answers, credentials, screenshots, archives, or source history from the private project.
- The interface is browser-only. Do not add a backend, network game session, upload, analytics, or persistence without an explicit privacy review.
- Run `npm test`, `npm run build`, and the relevant Playwright checks for behavior changes.
- Keep third-party assets out unless redistribution rights and attribution are verified. Preserve package license notices; do not add a project-wide license without approval.
- Do not add or push a GitHub remote until the sanitized initial commit and inventory are approved.
- Report changed files, behavior, tests, privacy scan results, and blockers. Never claim a feature is tested without passing test evidence.
